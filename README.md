# 📊 Учебная нагрузка преподавателя (АС Нагрузка - ММИС)

[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://www.python.org/)
[![PyQt6](https://img.shields.io/badge/GUI-PyQt6-green.svg)](https://www.riverbankcomputing.com/software/pyqt/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Десктопное приложение для автоматизированного формирования, настройки и экспорта отчётов по учебной нагрузке преподавателей из базы данных «Деканат» (MS SQL Server) в формат Excel. Разработано для интеграции с **АС Нагрузка - ММИС**.

## ✨ Возможности

- 🔌 **Гибкое подключение:** Поддержка Windows и SQL Server аутентификации с безопасным сохранением параметров.
- 🎛 **Расширенная фильтрация:** Выбор по кафедрам, преподавателям, годам, типам нагрузки, курсам и формам финансирования.
- 📝 **Кастомизация шаблонов:** Изменение шапки учреждения, ФИО утверждающих и начальника УМО прямо из интерфейса без правки кода.
- 📂 **Умное сохранение:** Автоматическая транслитерация ФИО в имени файла (`20260315_Ivanov_I_I.xlsx`), выбор локальной или сетевой папки.
- 📜 **История отчётов:** Встроенный журнал сгенерированных файлов с возможностью быстрого открытия.
- ⚡ **Пакетная генерация:** Массовое создание отчётов для всей кафедры одним кликом.
- 🔄 **Автообновление:** Тихая проверка актуальной версии приложения через JSON-манифест.

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Интерфейс:** PyQt6
- **Работа с БД:** `pyodbc` (Microsoft SQL Server)
- **Экспорт данных:** `openpyxl`
- **Сборка:** PyInstaller (формат standalone `.exe`)

## 🚀 Быстрый старт (для пользователей)

1. Убедитесь, что на компьютере установлен [ODBC Driver 17 for SQL Server](https://learn.microsoft.com/ru-ru/sql/connect/odbc/download-odbc-driver-for-sql-server).
2. Скачайте последнюю версию `УчебнаяНагрузка.exe` из раздела [Releases](../../releases).
3. Запустите приложение, введите данные сервера и нажмите **«Подключиться и загрузить списки»**.
4. Настройте фильтры и нажмите **«Сформировать отчёт»**.
